
# 🔍 Expandable Search Bar

A sleek, smooth, and fully interactive expandable search bar component built using pure HTML5 and CSS3 (using hidden checkbox hack for toggle interactions).

## 🚀 Live Demo

Coba langsung projeknya di sini:
👉 [https://sholihdinrizky.github.io/expandable-search-bar/](https://sholihdinrizky.github.io/expandable-search-bar/)

## 🛠️ Fitur & Teknologi

- **Pure HTML5 & CSS3**: Tanpa JavaScript.
- **Smooth Animation**: Animasi ekspansi input bar yang halus saat ikon pencarian diklik.
- **Clean UI**: Desain minimalis dengan palet warna modern.
